# Vellore Blood Bank Website

A comprehensive blood bank management system that connects blood donors with recipients across multiple locations in India.

## Project Overview

The Vellore Blood Bank website is a platform designed to facilitate blood donation and distribution. The system allows users to register as donors, find blood donors by location and blood type, track donation history, and connect with blood banks across India.

## Features

- **User Registration**: New donors can register by providing personal and medical information
- **Donor Dashboard**: Registered users can access their donation history, find recipients, and schedule donations
- **Donor Search**: Users can search for blood donors based on location, blood type, and availability
- **Donation Process**: Step-by-step guide for the blood donation process
- **Blood Bank Information**: Details about blood bank locations across India
- **Recent Activities**: Updates on blood donation camps and events
- **Contact Information**: Ways to reach the blood bank team

## File Structure

- `1.title page.html` - Homepage with user login, registration, and donor search functionality
- `2.register page.html` - Registration form for new donors
- `3.dashboard.html` - User dashboard with donation history and donor search
- `4.who can donate.html` - Information about blood donation eligibility
- `5.why to donate.html` - Information about the importance of blood donation
- `6.contact page.html` - Contact information for the blood bank
- `7.aboutus.html` - Information about the blood bank's history and locations
- `8.actvities.html` - Recent blood donation events and activities
- `9.styles.css` - CSS styles for the website

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download the repository
2. Open `1.title page.html` in your web browser to start

## User Flow

1. New users register via the registration page
2. Users log in with their credentials from the homepage
3. After login, users can access their dashboard with donation history
4. Users can search for donors based on location and blood type
5. Users can schedule their next donation through the dashboard
